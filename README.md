# ipynb → PDF

Convert Jupyter Notebook (`.ipynb`) files to PDF entirely in your browser.

- No server, no upload — notebooks are parsed and rendered locally in JavaScript.
- Renders markdown cells, syntax-highlighted code cells, and outputs (text, images, HTML, errors).
- Drop in as many `.ipynb` files as you want.
- Click "Convert & Download All" to convert every notebook and download them all at once — a single file if you loaded one notebook, or a `notebooks-pdf.zip` bundle if you loaded several.

## Usage

Open `index.html` (or the hosted GitHub Pages site) in a browser, drop in one or more `.ipynb` files, and click "Convert & Download All".

## Local development

This is a static site with no build step — just open `index.html` in a browser, or serve the folder with any static file server.
