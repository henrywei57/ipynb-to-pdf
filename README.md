# ipynb → PDF

Convert Jupyter Notebook (`.ipynb`) files to PDF entirely in your browser.

- No server, no upload — your notebook is parsed and rendered locally in JavaScript.
- Renders markdown cells, syntax-highlighted code cells, and outputs (text, images, HTML, errors).
- Click "Download PDF" to export the rendered notebook.

## Usage

Open `index.html` (or the hosted GitHub Pages site) in a browser, drop in a `.ipynb` file, and download the PDF.

## Local development

This is a static site with no build step — just open `index.html` in a browser, or serve the folder with any static file server.
